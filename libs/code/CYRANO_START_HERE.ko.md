# Cyrano Agent 개발 시작

현재 폴더 `libs/code/`가 AI 개발 에이전트 실행 위치다. dcode 기본 source 옆의 `deepagents_code/cyrano/`는 우리가 개발할 코드다. `cyrano/`는 개발 자료이며 Base를 대신하지 않는다.

[개발 수행 가이드](cyrano/docs/execution/R5_EXECUTION_GUIDE.ko.md), [구현 요청](cyrano/IMPLEMENTATION_REQUEST.ko.md), [문서 탐색](cyrano/docs/NAVIGATION.ko.md)을 읽는다. 설치/복사 도구는 프로젝트 밖에서 사용하고 제품 기능이 자동 활성화됐다고 가정하지 않는다.
