# 출처와 배포 범위

이 프로젝트는 deepseek-ai/deepseek-harness의 공개 구조·문서 계층·plugin 수명주기 원칙을 참고해 새 Python/dcode 프로젝트로 구성했다. 해당 upstream 제품 코드를 vendoring하거나 Cordis runtime을 복사하지 않았다. 조사 snapshot과 문서는 docs/sources.md에 기록한다.

references/interview 및 references/dream은 사용자가 제공한 설계 자료의 원문 보존 사본이다. 이 파일에 다른 저작물의 이용 허가를 새로 부여한다는 의미는 없다. 외부 자료를 실제 제품에 복사·배포할 경우 해당 원래 조건을 별도로 확인한다. 프로젝트 공개 전 소유자가 제품 라이선스·NOTICE 정책을 결정한다.
