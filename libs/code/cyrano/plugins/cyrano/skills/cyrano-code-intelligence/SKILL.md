# cyrano-code-intelligence

범위를 먼저 확인한다. 작은 lexical 탐색→지원되는 symbol query→관련 참조·원본을 읽는다. code_query capability가 없으면 없다고 표시한다. stale index나 inferred edge를 실행 사실로 판단하지 않는다. 직접 LSP edit·MCP shell·install을 수행하지 않고 승인된 Broker에 patch를 제안한다. 필요한 tool recipe와 usage는 담당 RF02/RF03의 readset에서 읽는다.

이 파일은 절차 원본이다. referenced runtime tool은 검증·활성화된 capability가 있을 때만 사용한다. 모델 이름별 custom prompt를 만들지 않는다.
