## 현재 계획 검토의 사례 연결

PLAN/REVIEW/HUMAN/CHANGE 사례는 단일 `tests/acceptance/catalog.json`에서 관리하며 이 평가항목의 rubric mandatory_case_ids에 연결한다. PLAN에는 interface·scope·test oracle·lineage, REVIEW에는 독립성·반증·재검토·상한·오류, HUMAN에는 표시본·목적·조건부/부분 승인·중복·만료, CHANGE에는 영향 closure·재승인을 포함한다. 실제 서비스 없이 schema만 통과한 결과는 준비 증거다.
