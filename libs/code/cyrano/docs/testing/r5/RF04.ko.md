When: 관련 작업 계획

Then: DB의 승인된 revision 회수·plan 반영 확인

구현: `../tests/cyrano_product/test_r5_rf04.py::test_rf04_01`; fixture `fixture_rf04_01`.

1. 고정 fixture snapshot·scope·runtime·정책·예산을 기록하고 별도 temp/home을 만든다.
2. A가 저장·종료; B 새세션 대화없음 상태를 준비하고 기준 원시 event/file manifest를 저장한다.
3. 관련 작업 계획 동작을 실제 소유 서비스로 실행한다.
