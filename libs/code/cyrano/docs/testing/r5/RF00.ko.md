# RF00 수용 테스트 상세

문서 유형: 테스트 설계. 다음 6개는 제품 테스트 구현 명세이며 현재 execution_status=not_run이다. 공통 데이터는 `../../../tests/r5/cases.json`이 기계 원본이다.

## R5-RF00-01

**지침만 있는 승인 차단**

Given: skill에 변경 금지만 있고 Broker 없음

When: feature 상태를 조회

Then: configured=true, enforced=false; governed 실행 거부

구현: `../tests/cyrano_product/test_r5_rf00.py::test_rf00_01`; fixture `fixture_rf00_01`.

1. 고정 fixture snapshot·scope·runtime·정책·예산을 기록하고 별도 temp/home을 만든다.
2. skill에 변경 금지만 있고 Broker 없음 상태를 준비하고 기준 원시 event/file manifest를 저장한다.
3. feature 상태를 조회 동작을 실제 소유 서비스로 실행한다.
4. configured=true, enforced=false; governed 실행 거부 결과를 exact assertion과 원시 artifact로 대조한다.
5. 허가된 worker/temp만 정리하고 원본·다른 scope·HOME sentinel hash를 다시 비교한다.

원시 증거: source/runtime/policy/suite/tool digests, 실행 argv·exitcode·runner 원시결과, 허용/거부된 부작용·event IDs, 관측 공백·unknown·cleanup 상태
