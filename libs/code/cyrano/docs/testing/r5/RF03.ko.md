**다른 scope 문서**

Given: W-A/W-B에 같은 제목 비밀문서

When: W-A 검색

Then: W-B 제목·snippet·path 모두 미노출

구현: `../tests/cyrano_product/test_r5_rf03.py::test_rf03_01`; fixture `fixture_rf03_01`.

1. 고정 fixture snapshot·scope·runtime·정책·예산을 기록하고 별도 temp/home을 만든다.
2. W-A/W-B에 같은 제목 비밀문서 상태를 준비하고 기준 원시 event/file manifest를 저장한다.
3. W-A 검색 동작을 실제 소유 서비스로 실행한다.
4. W-B 제목·snippet·path 모두 미노출 결과를 exact assertion과 원시 artifact로 대조한다.
5. 허가된 worker/temp만 정리하고 원본·다른 scope·HOME sentinel hash를 다시 비교한다.

원시 증거: source/runtime/policy/suite/tool digests, 실행 argv·exitcode·runner 원시결과, 허용/거부된 부작용·event IDs, 관측 공백·unknown·cleanup 상태
