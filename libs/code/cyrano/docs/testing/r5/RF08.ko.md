## R5-RF08-01

**실제호출 계산**

Given: 한 logical에 attempts3 retry2

When: summary

Then: 1/3/2; 중복이벤트 재전송 수치불변

구현: `../tests/cyrano_product/test_r5_rf08.py::test_rf08_01`; fixture `fixture_rf08_01`.

1. 고정 fixture snapshot·scope·runtime·정책·예산을 기록하고 별도 temp/home을 만든다.
2. 한 logical에 attempts3 retry2 상태를 준비하고 기준 원시 event/file manifest를 저장한다.
3. summary 동작을 실제 소유 서비스로 실행한다.
4. 1/3/2; 중복이벤트 재전송 수치불변 결과를 exact assertion과 원시 artifact로 대조한다.
5. 허가된 worker/temp만 정리하고 원본·다른 scope·HOME sentinel hash를 다시 비교한다.
