## 함수 구현 계약

### `resolve(tool, consent)`

공식 package/commit만 resolve; transitive lock·raw 명령·license inventory 저장. 입력은 trusted service에서 scope·revision을 바인딩하고 JSON/process/file 경계에서 검사한다. 예산·deadline·취소를 전달하며 unknown outcome은 retry로 덮지 않는다. 결과는 immutable artifact와 상태·원시근거 참조를 반환한다. DB 변경과 해당 control event·outbox는 같은 transaction, 외부 호출은 intent/result 두 단계로 기록한다. 모델에는 반환값의 공개 projection만 전달한다.

### `install(tool, lock_receipt)`

hash와 source revision 확인 후 격리 설치; 불완전 설치 비활성. 입력은 trusted service에서 scope·revision을 바인딩하고 JSON/process/file 경계에서 검사한다. 예산·deadline·취소를 전달하며 unknown outcome은 retry로 덮지 않는다. 결과는 immutable artifact와 상태·원시근거 참조를 반환한다. DB 변경과 해당 control event·outbox는 같은 transaction, 외부 호출은 intent/result 두 단계로 기록한다. 모델에는 반환값의 공개 projection만 전달한다.

### `probe(tool, sandbox)`

version/help/기능·파일/네트워크 부작용 결과를 ProbeReport로 반환. 입력은 trusted service에서 scope·revision을 바인딩하고 JSON/process/file 경계에서 검사한다. 예산·deadline·취소를 전달하며 unknown outcome은 retry로 덮지 않는다. 결과는 immutable artifact와 상태·원시근거 참조를 반환한다. ## 구현 순서

1. 입력/출력/오류 schema와 누락·권한·stale 반례를 먼저 작성한다.
2. 소유 서비스의 순수 판정과 I/O provider를 분리하고 필요한 DB migration을 추가한다.
3. 실제 dcode/도구 연결부는 source symbol·버전·capability를 재확인한 뒤 구현한다. 미지원은 capability unavailable로 보고한다.
4. 정상 경로에 같은 scope·원시 근거·취소·idempotency를 연결한다.
5. 아래 모든 수용 사례와 기존 owner WP의 회귀를 실행한다.
6. 독립 리뷰 finding을 처리하고 canonical 문서/설정/schema/source를 함께 갱신한다.

## 실제 검증 명령

```bash
# libs/code에서 실행. 첫 명령은 해당 product test를 구현한 이후에만 유효하다.
uv run --no-sync pytest tests/cyrano_product/test_r5_rf01.py -q
python cyrano/scripts/dev.py check
python cyrano/scripts/dev.py schemas
python cyrano/scripts/check_r5.py
python cyrano/scripts/dev.py quality
```

수용 테스트가 아직 없거나 0개/skip이면 미실행·차단이다. 이 ZIP의 순수 기반 테스트는 해당 제품 수용을 대체하지 않는다. 외부·native 실행에는 실제 허가와 환경이 필요하다.

## 인수·오류·복구

R5-RF01-01; R5-RF01-02; R5-RF01-03; R5-RF01-04; R5-RF01-05; R5-RF01-06 모두 실제 owner interface에서 검증한다. 인증·기준·회귀 hard gate를 비용으로 상쇄하지 않는다. 설치/실행 실패는 기왕 성공한 코드 결과를 조작하지 않고 별도 job 결과로 남긴다. 공유 source·DB·lock은 임의 rollback하지 않는다. 해당 receipt가 소유한 immutable generation을 정리하고 재시도할 때 source/runtime/release를 재검증한다.
