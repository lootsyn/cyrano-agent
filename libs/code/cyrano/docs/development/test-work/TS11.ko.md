## 구현·검증 절차

upstream 회귀와 CYRANO owned delta를 모두 검사한다. zero/skip/xfail/deselected를 mandatory PASS로 처리하지 않고 source가 바뀌면 증거를 다시 생성한다. native install/wheel/entrypoint와 실제 branch protection을 검증한 뒤 운영자가 결과를 확정한다.

각 함수의 입력은 source/runtime/policy/suite 및 현재 revision으로 결속한다. 성공은 typed artifact, 거부는 안정된 error code, 불확실 외부 결과는 unknown_outcome으로 반환한다. 공유 상태 mutation은 CAS와 event/outbox transaction을 사용한다.
