## 구현·검증 절차

exact main SHA와 dcode project.name·sibling 경로를 확인한다. 깨끗한 native preimage에서 overlay를 dry-run한 뒤 file collision과 AGENTS append를 검토한다. snapshot은 tracked+허용 untracked bytes를 포함하고 제외목록을 봉인한다.

각 함수의 입력은 source/runtime/policy/suite 및 현재 revision으로 결속한다. 성공은 typed artifact, 거부는 안정된 error code, 불확실 외부 결과는 unknown_outcome으로 반환한다. 공유 상태 mutation은 CAS와 event/outbox transaction을 사용한다.
